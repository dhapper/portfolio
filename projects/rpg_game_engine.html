RPG Game Engine

A real-time Java RPG game engine has been developed to power immersive and engaging gaming experiences. The featured game, created using this engine, showcases an intricate system for NPC and environment interactions, allowing players to explore a rich and responsive world. Key features include dynamic dialogues that unfold over time, offering players the option to read at their own pace or skip ahead. Furthermore, the engine seamlessly supports transitions between different locations, enhancing the overall narrative flow and player experience.
